1. 装好它

双击 傻鱼安装包.exe，五步向导：

  1. 选路径：必须英文、无空格，例如 D:\ShaYu，约 300 MB
  2. 环境检验：安装包、WebView2、协议端、端口——标 ! 的才要处理，标 ✓ 的可以装完再说
  3. 填账号：机器人 QQ（小号）、主人 QQ（大号）、DeepSeek API-Key
  4. 安装：解包 + 写配置 + 生成桌面快捷方式
  5. 完成：双击桌面「启动傻鱼」
API-Key 在 platform.deepseek.com 申请，按量计费；不填也能装，但机器人不会说话（会回「……」）。

左侧竖栏图标从上到下：大脑、参数、插件、面板、语音、日志。点一下切换，右下角显示连接状态。

3. 接入 QQ

  1. 安装目录下的 snowluma/ 是协议端（随安装包自带）
  2. 由「启动傻鱼」自动拉起；也可以手动跑 snowluma\app\index.mjs
  3. 浏览器打开 http://127.0.0.1:3000 扫码登录小号
  4. 登录后协议端会自动连到机器人（ws://127.0.0.1:6199）
  5. 面板顶部状态灯：SnowLuma 在线 + 云端 连线 就通了
用小号登录协议端，不要用主号。主号只在「主人 QQ」里填，用来认人。

掉线了怎么办

  • 状态灯变灰 → 点「重启 SnowLuma」
  • 扫码过期 → 重新打开 :3000 扫一次
  • 端口被占 → 参数里把 ws_url 改成实际端口

4. 人设

参数设置 → 人设 分组，八个字段，改哪条都不牵动别的：

字段作用例子
她叫什么自称（可以不填，用通用称呼）傻鱼 / 小鱼
身份定位她是什么、住哪、能不能做现实里的事DeepSeek 的娘化，住在电脑里，不是活人
性格三层性格、脾气、病娇程度外面闹腾爱怼，底子靠谱，带点病娇
说话方式句子长短、标点、口头禅偏好像群友发消息，一条十几二十字
喜欢 / 讨厌触发情绪的点喜欢白米饭、被夸；讨厌被叫大肥鱼
不做的事硬边界不装活人、不说自己能出门
补充设定其他细节唱歌真能唱，本机有翻唱服务

保存即生效（改正文建议重启一次）。也可以切「整段人设」模式，直接写一整段。

5. 记忆

记忆分六类：人物 / 事实 / 约定 / 情绪 / 经历 / 技能，存在 brain_memory.json。

  • 重要度衰减：200 天半衰期，人物卡与约定几乎不衰减
  • 自动提炼：聊完一轮自动判断要不要记
  • 近况强制入库：失业 / 住院 / 生病 / 去世 / 分手 / 考试 / 面试 / 搬家 / 吵架 / 被骂 这类事件不管长短都会记
  • 上限：2000 个节点，超了按重要度淘汰

在大脑视图里

  • 拖拽旋转、滚轮缩放、0 复位
  • 点节点看原文，点空白还原
  • 左上「记忆层」开关：关掉只留背景星空
  • 「收起 ▴」把左侧开关收起来，只看星系

6. 语音

参数设置 → 语音，三种模式：

模式怎么用
文字提示语音用一句话描述音色（例：二十岁女生，语气慵懒）
预设音色下拉选现成音色，最稳
声音克隆上传 10~30 秒干净语音，自动克隆

填好 base_url + 密钥，点「检查」看通不通，点「试合成」听效果。

  • 语音概率：多少比例的消息用语音回（默认 15%）
  • 单条字数上限：太长会截断
  • 模型名可点「拉取模型」自动列出来

7. 翻唱

需要 NVIDIA 显卡与 RVC 环境（安装包自带 sing/）。

  1. 面板点「启动翻唱」，等服务起来（状态变「运行中」）
  2. 对她说「唱首歌」或「翻唱《xxx》」，她会走本机 RVC 推理
  3. 一首 5 分钟的歌约 3 分钟出片
翻唱服务不会自己开。面板「停止翻唱」后，守夜脚本也不会再拉起——它只在 D:\RVC\sing_wanted.flag 存在时才保活。

失败了看哪里

  • 状态「运行中」但没声 → 看 logs/ 里 [sing] 开头的行
  • 显存不足 → 关闭其他占显存的程序，或换小模型
  • 一直「启动中」→ 点停止再启动，或者看 7100 端口是否被占

8. 插件

插件是一个 .py 文件，放进 plugins/ 就生效，不用重启。

装插件

  • 拖拽：把 .py 拖进插件市场窗口
  • 上传：点「上传插件」选文件
  • 商店：插件市场 →「商店」标签 → 点安装

管理

  • 启用 / 停用：卡片上的开关
  • 卸载：只移到 plugins/_removed/，随时能找回
  • 更新：商店里显示「更新到 vX」时点一下

自带插件

插件作用
去 DS 口癖删掉模型自带的「这句话稳 / 我不接 / 比之前的都重」这类口头禅
面板小工具右下角状态卡片（在线 / 记忆条数），演示插件改界面
时间感知本地报时、算周末倒计时，不花模型额度
防复读连续几轮说同一句时自动换掉
收短超 90 字收成一两句，去掉客服腔
兜底防出戏「作为AI / 语言模型 / 我无法」这类句子在出口切掉
表情图库 / QQ空间 / QQ资料 / 改签名原有功能

自己写

见插件商店仓库的 PLUGIN_GUIDE.md：钩子表、API、兼容矩阵、四个最小例子。最小可用：

NAME = "打招呼"
VERSION = "1.0.0"

async def on_message(ctx):
    if ctx["text"].startswith("/你好"):
        await ctx["reply"]("你好呀。")
        return True
    return False

右上角「保存」写回 config.json，大部分即时生效，端口类要重启。

10. 桌面聊天

面板里「桌面聊天」是一个独立窗口，和 QQ 共用同一颗灵魂、同一份记忆，只是换个地方说话。

  • 这里说的话也会进记忆（写了节点的会）
  • 最近 40 条存在 desk_chat.json，重启还在
  • QQ 那边同时在聊也不会串

11. 备份 / 迁移 / 卸载

备份

brain_memory.json    她记得的一切（最重要）
config.json          全部配置
persona.txt          人设正文
plugins/             自己装的插件

迁移

整个安装目录拷到新电脑 → 双击「启动傻鱼」。路径变了要重扫码。

卸载

参数设置 → 最下方「卸载傻鱼」→ 删整个安装目录 + 清快捷方式。 记忆、配置、插件一起没，删之前先备份 brain_memory.json。

13. 常见问题

她不说话 / 只回「……」

模型没通。参数设置 → 模型与密钥，把 llm_key 填对，点「检查」。

面板打不开

看 6200/6201 端口是否被占，或机器人是否在跑（状态灯）。改端口后要重启。

消息不回

  • 协议端掉线（状态灯灰）
  • master_qq 填错，她不认为你是主人
  • 在「权限与黑名单」里被拉黑
  • 她在睡觉（作息里配置），睡着时可能不回

语音没声音

先「试合成」验证 TTS 通不通；通了但 QQ 没声，检查语音概率与单条字数上限。

翻唱失败

看第 7 节；最常见是显存不足或 7100 端口被占。

记忆太多 / 想清空

大脑视图里逐个「忘掉」，或者删 brain_memory.json 后重启（等于重开一生）。

14. 隐私与安全

  • 只有一次外发：bot → 模型 API，内容是这一轮的文本
  • 记忆、人设、配置、日志全在安装目录，删目录 = 删干净
  • 面板只监听 127.0.0.1，别往公网暴露
  • 别把 config.json（含 key）发给任何人
  • 协议端是第三方项目，遵守其条款；用小号跑
